# 桌面端交互与布局

桌面首页采用一个窗口内的模式切换、本机可接收状态、远端连接表单和近期连接。这些分区参考 CrossDesk 官方的桌面与 IP 直连预览。NexDesk 使用自己的配色、控件、文案和产品流程。[CrossDesk 界面预览](https://github.com/kunkundi/crossdesk/blob/mcp/README_ZH.md#preview)

## 首页

```text
┌─────────────────────────────────────────────────────────────────┐
│ NexDesk                                            设置         │
├─────────────────────────────────────────────────────────────────┤
│ [ ID 连接 ] [ IP 直连 ]                                         │
│                                                                 │
│ ┌ 本机设备 ────────────┐  ┌ 连接远程设备 ────────────────────┐ │
│ │ 接收状态             │  │ 设备 ID 或 IP 和端口              │ │
│ │ 本机 ID 或监听地址   │  │                                  │ │
│ │ 查看/重置连接密码    │  │                        [ 连接 ]  │ │
│ └──────────────────────┘  └──────────────────────────────────┘ │
│ ┌ 近期连接 ──────────────────────────────────────────────────┐ │
│ │ 当前模式内的设备、最后连接时间和重连操作                    │ │
│ └────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

桌面宽窗口将两个主要区块并排，窄窗口改为上下排列，保留键盘导航和滚动。近期设备为空时展示当前模式的空状态。底部状态用图标和文本同时提示目录和监听状态。打开软件后自动准备连接，在本机卡显示当前模式的地址和连接密码。用户可以隐藏或重置密码，来访连接仍需要本机授权。

### 设备 ID 模式

设置里的当前 ID 服务同时用于本机注册与查找远端。发行版有默认地址时自动使用，也可以开启自托管，保存域名与外部 HTTPS 端口。首页右侧只填九位 ID，粘贴时保留前导零。目录切换后展示新目录分配的 ID。没有配置目录时，从设置添加自托管服务。

### 局域网直连模式

本机卡显示实际监听的 IP 和端口。远端输入框接受 IP、IP 与端口组合，以及带方括号和端口的 IPv6 地址。省略端口时使用 53980。网卡、端口与允许来访的策略在设置中管理。目录变更只更新 ID 接收，两个模式使用独立密码。

### 近期开关与凭据

每条历史记录可显示设备标签、地址、上次成功时间、重连和更多操作。移除操作包含是否清除关联的系统凭据。模式切换保留地址草稿，密码按认证窗口生命周期管理。若设备身份变化，重连界面显示对端身份需要重新确认。

## 认证、授权和连接状态

1. 连接表单校验通过后打开共用密码对话框。输入远端密码时默认遮挡，可以用保存的密码或选择记住新密码。
2. 提交后发起认证和媒体协商，连接窗口展示进度和取消操作。首次连接继续核对设备身份。
3. 被控方查看请求来源和本次权限摘要，可以按摘要批准、仅允许观看或拒绝。首次信任主控设备时可勾选信任期限。超时和拒绝分别提示。
4. 建立会话后单独打开会话窗口，首页仍可管理设备。失败时保留地址和端口，清除密码，根据错误提示可行操作。
5. 被控方在主窗口或托盘查看当前连接，并可直接结束。系统权限缺失提供对应设置入口和重试。

## 远程会话窗口

```text
┌ 被控设备 · 显示器 1 ── 切屏  画质  声音  组合键  文件  全屏  断开 ┐
│                                                                 │
│                      远程画面（等比显示）                         │
│                                                                 │
└ 控制状态 ──────────────────────────────── 直连 / 中继 · 网络状态 ┘
```

顶栏显示设备名称、显示器、连接状态。主要操作为控制/只读、显示器切换、画质与帧率、音频、发送组合键、文件、全屏和断开。低频操作放入菜单；禁用项提供具体原因。画面初始等比适配，有独立的 1:1、画布缩放与位置平移。屏幕区域失焦、窗口隐藏或打开本地对话时释放远端按键。

显示器分辨率设置区分别标出远端显示模式、实际编码尺寸和本地缩放。切换物理模式后显示倒计时、确认和恢复；只在被控端实际生效且主控确认后保存选择。全屏模式有始终可访问的退出方式。重连时覆盖说明当前状态，停止发送输入。

## 文件传输窗口

```text
┌ 文件传输 · 被控设备 ─────────────────────────────────────────────┐
│ 本机 › 当前目录             │ 远端 › 当前目录                    │
│ 文件 / 文件夹列表            │ 文件 / 文件夹列表                  │
│              [ 发送到远端 ]  │ [ 接收到本机 ]                     │
├─────────────────────────────────────────────────────────────────┤
│ 任务             方向           进度           暂停 / 取消       │
└─────────────────────────────────────────────────────────────────┘
```

本机与远端分别占一栏，上方显示面包屑路径和权限，正文显示列表及多选。工具栏明确“发送到远端”和“接收到本机”。拖放时突出目标端及目录。大量文件先展示项目数量，询问冲突策略；底部任务区显示状态、速度、进度、重试和取消。窄窗口使用可切换的本机与远端视图，目的地一直可见。

## 设置页

| 分区 | 控件和说明 |
| --- | --- |
| 连接 | 默认或自托管服务、HTTPS 地址和端口、测试连接、允许 IP 来访、网卡及本机监听端口 |
| 权限 | 主控默认请求权限、本机设备授权、被控端允许的权限上限 |
| 共享 | 初始显示器、被控端共享路径、系统录屏权限和 ID 会话的 Shell 请求策略 |
| 画面 | 本机发起新会话时的默认画质和帧率上限 |
| 存储 | 双栏文件管理使用的默认本机接收路径 |

保存时先校验目录和监听地址。如果会结束当前会话，可以等会话结束再应用。登录后自启动、托盘、隐私屏和受信设备名单属于后续的系统能力。 [发布路线图](roadmap.md)

主控默认使用“日常远控”，请求键鼠、声音、文本剪贴板和输入法文本。“仅观看”保留画面和可用的系统声音。“完整远控”还可申请共享目录的文件读写和分辨率调整。“自定义”用于在设置中逐项修改。新安装的被控端允许审批所请求的普通权限，实际能力仍受主控请求、被控设置、系统支持和本次批准范围限制。远程 Shell 由被控端单独批准。
