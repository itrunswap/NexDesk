# 桌面端交互与布局

桌面首页集中管理连接方式、本机凭据、远端地址和近期设备。正常连接在第一帧就绪后打开独立的远程桌面窗口。页面操作参考 CrossDesk v1.7.7 的连接流程，界面沿用 NexDesk 的配色和控件。[CrossDesk 桌面使用指南](https://github.com/kunkundi/crossdesk/blob/v1.7.7-20261124/docs/USER_GUIDE.md#快速连接)

## 首页

```text
┌─────────────────────────────────────────────────────────────────┐
│ [ ID 连接 ] [ IP 直连 ]                     共享中  设置        │
│                                                                 │
│ ┌ 本机设备 ────────────┐  ┌ 连接远程设备 ────────────────────┐ │
│ │ 接收状态             │  │ 设备 ID 或 IP 和端口              │ │
│ │ 本机 ID 或监听地址   │  │                                  │ │
│ │ 查看/重置连接密码    │  │                        [ 连接 ]  │ │
│ └──────────────────────┘  └──────────────────────────────────┘ │
│ ┌ 近期连接 ──────────────────────────────────────────────────┐ │
│ │ 当前模式内的设备名称、分组、连接或返回会话窗口              │ │
│ └────────────────────────────────────────────────────────────┘ │
│ ● 本机连接状态                                         v0.1.7  │
└─────────────────────────────────────────────────────────────────┘
```

桌面宽窗口将两张等高卡片并排，窄窗口上下排列。连接方式与设置位于同一行。底栏左侧显示本机连接状态，右侧显示当前构建版本。收到来访时，右上角「共享中」可查看来访地址、控制权限和断开入口。

### 设备 ID 模式

设置里的当前 ID 服务同时用于本机注册与查找远端。发行版有默认地址时自动使用，也可以开启自托管，保存域名与外部 HTTPS 端口。首页右侧只填九位 ID，粘贴时保留前导零。目录切换后展示新目录分配的 ID。没有配置目录时，从设置添加自托管服务。

### 局域网直连模式

本机卡显示实际监听的 IP 和端口，可以复制完整地址，从本机网卡下拉选择 IP，或就地修改端口。远端输入框接受 IP、IP 与端口组合，以及带方括号和端口的 IPv6 地址。省略端口时使用 53980。ID 和 IP 使用独立密码，各自支持点击复制密码、显示或隐藏、生成随机密码和手工修改。

远端输入框为空时提供粘贴入口，有内容时可一键清空。支持粘贴带空格的设备 ID，也会处理 IP 和端口分隔符两侧的空格。点击「连接」和按回车使用同一套校验。错误显示在对应输入框，切换模式时保留各自的输入草稿。

### 近期连接与凭据

近期设备按 ID 或 IP 分开显示，可编辑别名、修改分组、筛选分组、清除保存的密码和移除记录。ID 设备可以主动查询目录在线状态。同一目标的会话已经打开时，卡片主按钮返回该窗口，菜单可以发起断开。ID 记录按目录服务和设备 ID 绑定，IP 记录按规范化的 IP 和端口绑定。模式切换保留地址草稿。

## 认证、授权和连接状态

1. 连接表单校验通过后收集六位密码。已经保存密码的近期设备可以直接连接。
2. 首页弹窗显示认证、等待授权和媒体协商进度，可以取消。错密码或保存凭据失效时可以重新输入。
3. 被控方按「设置 → 共享 → 接入方式」进行授权。首次连接成功后，主控记录被控设备身份。后续身份不符时提示核对设备。
4. 主控收到第一帧后创建独立窗口，原窗口可继续管理设备。两个窗口交接同一条 Rust 会话，启动参数传递会话句柄和显示配置，密码留在连接核心中。[CrossDesk 连接与窗口架构](https://github.com/kunkundi/crossdesk/blob/v1.7.7-20261124/docs/gui-architecture.md#建立-id-远端连接)

## 远程会话窗口

```text
┌ NexDesk · 设备别名和地址 ────────────────────────────────────────┐
│                                                    [会话操作]   │
│                      远程画面（等比显示）                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

系统标题栏显示设备别名和地址。右上角悬浮按钮展开连接状态、显示器、缩放、组合键、暂停和恢复控制、画质、声音、文件、剪贴板、网络统计、全屏及断开。工具按会话权限和远端能力出现。画面初始等比适配，支持原始像素和放大平移。会话失焦或打开本地对话时释放远端按键。关闭会话窗口或点「断开连接」时，确认后结束当前会话。主页可以和多个远控窗口并存。

CrossDesk 还提供桌面墙、画面缩略图、隐私屏和系统文件剪贴板。这些功能各自依赖额外的媒体、存储或平台能力，本次交互对齐覆盖普通桌面连接、近期设备及其独立会话。[CrossDesk 会话操作](https://github.com/kunkundi/crossdesk/blob/v1.7.7-20261124/docs/USER_GUIDE.md#会话中的常用操作)

「画质」在当前会话中调整模式、传输分辨率上限、帧率上限和视频码率上限。分辨率上限在被控端编码前等比缩小画面，远端屏幕和键鼠坐标仍以原采集区域为准。实际像素取决于远端画面尺寸、网络、编解码能力和本地窗口。需要完整查看细节时，可选择「原始像素」，按本机的物理像素等比显示。

「连接与媒体统计」分别显示远端采集、送入编码、实际发送、本机解码和本地绘制尺寸，同时显示生效的编码格式、两端的编解码实现、接收码率、帧率、丢包和质量受限原因。对于发送画面已经达到所选分辨率的会话，可用本地绘制尺寸判断等比适配带来的缩小。

「显示器」用于切换共享屏幕和远端显示模式。切换物理模式后显示倒计时、确认和恢复，实际生效并经主控确认的选择会被保存。全屏模式可以从悬浮菜单退出。重连时覆盖说明当前状态并停止发送输入。

## 文件传输窗口

```text
┌ 文件传输 · 被控设备 ─────────────────────────────────────────────┐
│ 本机 › 当前目录             │ 远端 › 当前目录                    │
│ 文件 / 文件夹列表            │ 文件 / 文件夹列表                  │
│              [ 发送到远端 ]  │ [ 接收到本机 ]                     │
├─────────────────────────────────────────────────────────────────┤
│ 任务             方向           进度           暂停 / 取消       │
└─────────────────────────────────────────────────────────────────┘
```

本机与远端分别占一栏，上方显示面包屑路径和权限，正文显示列表及多选。工具栏明确“发送到远端”和“接收到本机”。拖放时突出目标端及目录。大量文件先展示项目数量，询问冲突策略；底部任务区显示状态、速度、进度、重试和取消。窄窗口使用可切换的本机与远端视图，目的地一直可见。

## 设置页

| 分区 | 控件和说明 |
| --- | --- |
| 常规 | 默认或自托管 ID 服务、目录连通测试、仅通过 TURN 中继、IP 来访及监听网卡和端口、默认传输画质、本机共享编码格式和硬件编码偏好、本机文件接收目录 |
| 权限 | 主控默认请求权限、本机设备授权、被控端允许的权限上限 |
| 共享 | 接入方式、可信设备管理、初始共享显示器、被控端文件共享目录、系统录屏权限和 ID 会话的 Shell 请求策略 |
| 维护 | 登录系统后启动、关闭窗口后保留托盘、本机诊断和待生效设置 |

自托管开关在默认和自托管 ID 服务之间切换。「编辑自托管」可以预先保存服务器地址与外部 HTTPS 端口，HTTPS 未填写端口时使用 443。编辑窗的「确认」更新草稿，主设置的「保存」应用配置。「测试连接」检查草稿中当前选用的目录是否可达及协议是否兼容。打开「仅通过 TURN 中继」后，从这台电脑新发起的 ID 会话仅使用 TURN，目录必须提供可用的 TURN 服务。IP 直连独立工作，自动监听模式选择一个可用的私网地址。修改会影响当前接收会话时，可以现在应用或在会话结束后应用。「维护」中的系统启动与托盘开关即时生效，具体能力取决于本机平台。

| 画质模式 | 选中模式时的初始上限 | 自适应策略 |
| --- | --- | --- |
| 自动 | 按远端尺寸、30 FPS | 平衡分辨率与帧率 |
| 文字清晰 | 1440p、30 FPS | 优先保持分辨率，自动码率上限 16 Mbps |
| 操作流畅 | 1080p、60 FPS | 优先保持帧率，自动码率上限 14 Mbps |

每个模式可进一步设置 720p、1080p、1440p 或 2160p，帧率上限和视频码率上限也可单独设置。这些默认值在本机发起新连接时发送给对端。被控端的「本机共享画面的编码格式」用于新进来的连接，提供自动、H.264、AV1 和 VP8。自动优先协商 H.264，AV1 缺少共同支持时协商 H.264 或 VP8。「优先硬件编码」决定发送端的编码后端偏好，实际实现可在会话统计中查看。

「可信设备免确认」接受已授权设备的复连，其他设备可发起手动申请。「仅允许已授权设备」要求匹配当前连接方式或当前 ID 服务下的有效设备授权，并验证连接密码。授权有效期为 30 天，授权范围以原批准的键鼠与协作权限为上限。新增时，先让被控端使用「可信设备免确认」，主控端打开「使用本机设备授权」，被控端批准来访时选择「信任此设备 30 天」。之后再在被控端启用「仅允许已授权设备」。新设备、过期授权和超出已授权权限的请求在该模式下直接拒绝。Shell 需要本机逐次批准，在仅允许已授权设备时关闭。

| CrossDesk 设置 | 作用与 NexDesk 的支持范围 |
| --- | --- |
| 视频编码格式 | 为新会话选择共享画面的首选编码格式，由两端共同协商 |
| 最小化时暂停视频 | 远程窗口最小化时暂停会话的视频流，以减少资源使用。NexDesk 暂未提供对应开关 |
| 启用 IP 连接、监听所有 IP 接口 | 前者允许 IP 来访，后者允许多块网卡同时接收。NexDesk 提供 IP 来访开关、单网卡选择和端口设置 |
| 强制中继、自托管配置 | 对齐本机发起 ID 会话的 TURN 选路和自托管服务编辑 |
| 隐私屏、允许本地解锁、断开后锁屏 | 分别遮住被控电脑的实体屏幕、允许本地解除遮挡、在最后一个控制会话断开后锁定系统。NexDesk 暂未接入这些系统能力 |
| 仅允许可信设备、管理可信设备 | 对齐名单限制与撤销，NexDesk 使用会话内批准登记设备 |
| 保存远程画面预览、文件接收路径 | 前者将画面缩略图关联到近期设备，后者设定本机接收文件的起始目录。NexDesk 已提供文件接收路径，缩略图待实现 |
| 开机自启、启用守护进程 | CrossDesk 的 Windows 安装版可登录前接收远控，守护进程负责异常退出后重新启动。NexDesk 支持登录后启动与托盘常驻，登录前控制和崩溃自拉起待实现 |

[CrossDesk 桌面设置](https://github.com/kunkundi/crossdesk/blob/v1.7.7-20261124/docs/USER_GUIDE.md#settings) · [CrossDesk 可信设备规则](https://github.com/kunkundi/crossdesk/blob/v1.7.7-20261124/docs/CONNECTIONS.md#trusted-devices)

主控默认使用“日常远控”，请求键鼠、声音、文本剪贴板和输入法文本。“仅观看”保留画面和可用的系统声音。“完整远控”还可申请共享目录的文件读写和分辨率调整。“自定义”用于在设置中逐项修改。新安装的被控端允许审批所请求的普通权限，实际能力仍受主控请求、被控设置、系统支持和本次批准范围限制。远程 Shell 由被控端单独批准。
