# 功能清单与验收

NexDesk 面向用户有权控制的电脑。首个完整桌面版本支持 Windows、macOS、Linux 的双向角色互通，提供浏览器主控、独立终端主控和自托管部署。手机和平板沿用主控协议，单独发布。各平台的权限和硬件能力由会话协商决定。

每项需求有稳定编号。阶段列指可按该行验收的最早里程碑。M0 只交付基础工程、首页和地址校验。完整交付顺序见 [实施计划](roadmap.md)，桌面交互见 [桌面设计](desktop-design.md)。

## 连接与设备

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| CON-01 | **桌面互控。** 同一个桌面应用可担任主控和被控端。被控端按用户授权共享当前桌面，主控显示当前设备和会话状态。 | Windows、macOS、Linux 作为主控和被控组合通过 3×3 验收。Linux 记录实际发行版和桌面环境。 | M2 |
| CON-02 | **双模式首页。** 模式切换同步更新本机信息、远端输入和近期列表。保留两种模式各自的地址草稿。离开模式时清空尚未提交的密码。 | IP 草稿与设备 ID 草稿分别保存。切换模式不会中断独立会话窗口。 | M2 / M4 |
| CON-03 | **局域网直连。** 主控填写 IP、独立端口和六位连接密码。使用本机监听完成认证及协商。首发支持可路由 IPv4 和 IPv6，地址输入接受 IPv6 方括号形式，链路本地带作用域地址单独验证后开放。 | 关闭互联网、公共 DNS 和服务器后，两台同网段电脑仍可连接、控屏、听音及传文件。 | M2 / M3 |
| CON-04 | **本机监听设置。** 用户选择可访问的网卡或私有网络，明确开启被控能力。入口端口默认 53980，可单独修改。WebRTC 媒体候选端口与入口分开展示和管理。 | 端口被占用时保留旧设置。尝试新绑定成功后再切换；主动停用监听终止该模式的会话。 | M2 |
| CON-05 | **六位连接密码。** 默认生成 6 个由系统随机源产生的 ASCII 字母或数字，区分大小写。LAN 与 ID 使用独立凭据及策略。支持重置；重置后旧密码失效。 | 允许含前导零，拒绝错误长度和非约定字符。错误尝试触发限速，密码不进入历史和日志。 | M2 / M4 |
| CON-06 | **设备 ID 连接。** 从选定自托管服务器获取九位设备 ID，主控按服务器和 ID 寻址。UI 允许复制 ID、检查在线状态和进入密码验证。 | 同一数字 ID 在不同服务器下可分别保存。带前导零的 ID 原样保留。设备离线有可识别提示。 | M4 |
| CON-07 | **自动选择网络路径。** ID 模式由 ICE 尝试直接连接，失败时使用配置的自托管 TURN。会话信息显示直连或中继。 | 两端跨网时可自动中继；中继不可用返回单独错误，LAN 模式不回落到网络服务。 | M4 |
| CON-08 | **记住密码与可信设备。** 选择记住后，由系统凭据库保存主控密码，并与已验证的被控设备身份及模式绑定。支持删除凭据和显式配对、撤销可信设备。 | IP 被其他设备复用时，客户端拒绝自动提交旧密码。历史列表删除或清除凭据后不能再自动填充。 | M2 / M4 |
| CON-09 | **按模式显示近期连接。** 成功完成身份确认并建立会话后更新最近使用时间、别名及地址；快速重连、重命名、移除。 | 失败和取消的连接不产生历史项。切换模式时不混入另一模式记录。 | M2 / M4 |
| CON-10 | **连接事务与恢复。** 针对发现、认证、等待同意、媒体协商、连接中断展示明确状态；支持取消，对临时断网做有界重试。 | 取消后释放资源；失效的会话或令牌无法恢复。重试不增加重复窗口和历史项。 | M2 |
| CON-11 | **会话入口和断开。** 主窗口可定位已打开会话。工具栏提供结束会话，被控设备也可立即断开。 | 任一方主动结束后释放输入、捕获、音频、连接和正在占用的资源。 | M2 |

## 权限、隐私与运行状态

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| SEC-01 | **首次连接确认。** 主控完成身份验证后，被控端按接入策略显示申请的能力和设备信息。本机用户可以仅允许观看、允许控制或拒绝。可信设备按已配置的范围授权。 | 加入同一网络或知道设备 ID 不授予访问权限。只读会话无法通过协议申请输入。 | M2 |
| SEC-02 | **细粒度会话能力。** 观看、听音、键鼠、文本剪贴板、文件读写、改分辨率及 Shell 各有授权范围。提升权限需要新授权，主机处理请求前再检查。 | 撤销能力后立即生效，已排队的操作也受新策略约束。界面和协议拒绝理由一致。 | M2–M6 |
| SEC-03 | **设备身份与端到端绑定。** 配对和密码认证确认设备公钥，媒体协商绑定本次认证和双方指纹。身份更换要求重新核对。 | 恶意转发或替换协商信息会被拒绝；信令和 TURN 不接触会话明文。 | M2 / M4 |
| SEC-04 | **可见的被控状态。** 接收远控时显示托盘或系统状态和正在连接的设备，提供停止或撤销入口。 | 即使关闭主窗口，本机仍能找到活跃会话并退出。系统录屏与辅助功能授权遵循平台提示。 | M2 |
| SEC-05 | **后台接收与无人值守。** 用户登录后可显式启用开机自启动和可信设备访问。锁屏、切用户、登录前和安全桌面由独立的平台能力决定。 | 默认关闭无人值守。未授权或当前桌面不可采集时给出明确状态；恢复也必须尊重现有授权。 | M7 |
| SEC-06 | **会话记录与凭据管理。** 提供连接/断开时间、匿名化错误和结果；支持查看配对、清除历史与撤销。 | 导出诊断不含密码、密钥、屏幕、剪贴板和文件正文；重置配对会踢出对应会话。 | M7 |

## 画面、显示器与声音

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| AV-01 | **硬件编码。** 优先选用可用的 H.264 硬件编码器。探测失败、驱动重置或协商失败时按策略使用软件编码并报告实际状态。 | 分别验证有硬编、硬编不可用和运行中失效三种场景。统计以实际使用的路径为准。 | M2 |
| AV-02 | **硬件解码与软件回退。** 原生客户端探测硬解，将可用的资源送入原生纹理。浏览器按自身的硬件支持工作。 | Windows、macOS、Linux 分别测解码路径、资源释放、CPU/GPU 占用和硬解失效后的回退。 | M2 / M4 |
| AV-03 | **清晰低延迟画面。** 提供自适应质量，在文本编辑和快速滚动间调整实际码率、帧率和尺寸。窗口支持等比适配、原始比例、全屏及独立缩放。 | 用代码、终端、表格及拖动场景对比文字可读性、采样和延迟；网络恢复时画面不积压。 | M3 |
| AV-04 | **会话质量与帧率设置。** 自动、清晰、流畅档位以及帧率上限可以在会话内修改；面板展示实际编码、尺寸、FPS 与回退原因。 | 调整后持续操作，设置结果有确认。同一质量档在弱网与高负荷时可以降级。 | M3 |
| AV-05 | **多显示器。** 列出当前可共享的显示器，按稳定标识切换。切换后更新分辨率、旋转信息、鼠标坐标和输入映射。 | 覆盖主副屏、不同 DPI、横竖屏及热插拔。失效显示器自动回到可用来源并告知用户。 | M2 |
| AV-06 | **远端分辨率切换。** 仅展示主机当前支持的实际显示模式。调整后读回生效值，由主控确认。具备回滚超时，支持会话结束恢复。 | 模式不支持、黑屏、断线或未确认时恢复先前模式。应用期间本机手动更改优先。 | M3 |
| AV-07 | **记住已确认的分辨率。** 按主机身份、显示器和连接模式保存确认后的选择。重连检查显示器、权限及模式兼容再尝试恢复。 | 未提交、已失败或回滚过的选择不入库。更换显示器后不应用旧配置。 | M3 |
| AV-08 | **远端系统音频。** 用户同意后抓取远端播放的系统声，经 Opus 传输。主控可静音、调整音量；设备切换或权限问题独立提示。 | 声音设备不可用时画面及输入继续工作。验证音画同步、换设备、静音解除和浏览器播放手势。 | M3 / M4 |
| AV-09 | **媒体状态与诊断。** 显示网络路径、RTT、视频帧率、实际码率、丢帧、排队延迟和编解码状态。 | 非关键统计按低频刷新，隐藏时减少采样，显示分开区分网络 RTT 与端到端测量。 | M3 |

## 键鼠、快捷键和剪贴板

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| IO-01 | **鼠标操作。** 支持点击、双击、拖动、滚轮和跟随主机配置的指针。绝对坐标按当前显示器、视口及边缘空白映射。 | 缩放、滚动、转屏和高 DPI 下点击位置准确。拖动结束后主机不会保持按下。 | M2 |
| IO-02 | **键盘与组合键。** 发送物理键、修饰键和明确的组合键。系统保留键由会话工具栏按能力处理。 | 测左/右修饰键、跨平台快捷键、连续输入、失焦、切屏、断线后的按键释放。 | M2 |
| IO-03 | **键盘布局和输入法。** 区分物理扫描键与已提交的文本，支持常用键盘布局和中文输入。密码框、游戏和系统窗口按实际输入能力标记。 | 中英文输入、切换布局、组合键在主控中分别走正确路径。 | M3 |
| IO-04 | **文本剪贴板。** 可授权双向同步或主动发送，限制大小，去重且防止回环。 | 确认 Unicode 文本、换行和空文本行为。关闭同步后不继续读取或写入。 | M3 |
| IO-05 | **控制权和输入恢复。** 同一被控桌面只允许一个会话持有输入控制权。支持从观看申请控制，撤销或断线时释放按键和按钮。 | 双客户端争抢时最多一方输入生效，过期输入和旧屏幕坐标被丢弃。 | M3 |

## 双栏文件传输

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| FS-01 | **本地与远端目录浏览。** 双栏各自显示路径、返回上级、刷新、排序和分页，标明端和当前目录权限。 | 大目录不阻塞画面或界面。远端无权访问的目录返回可理解的拒绝。 | M3 |
| FS-02 | **双向文件传输。** 选择一项或多项后显式发送到另一侧当前目录，支持零字节文件和大文件。 | 主控上传和下载各自支持；正常接收后内容和完整性校验一致。 | M3 |
| FS-03 | **文件夹递归与拖放。** 扫描目录清单，保留层级和空目录。允许在文件面板拖入明确目的端，先预览目标、冲突和数量。 | 不跟随未授权的链接或重解析点。拖放方向、相对路径和最终位置与预览一致。 | M3 |
| FS-04 | **冲突与提交。** 重名时提供覆盖、保留两份、跳过。接收端校验后在同一文件系统提交临时文件。 | 磁盘空间不足、权限拒绝和取消不会留下冒充完成的目标文件；覆盖需明确选择。 | M3 |
| FS-05 | **任务管理与断点续传。** 显示排队、扫描、传输、暂停、重试、完成和失败。连接恢复后根据同一设备、文件标识和已确认范围续传。 | 断网后保留进度；源文件变化、权限变化或校验不符时拒绝续传并给出原因。 | M3 |
| FS-06 | **文件传输让出带宽。** 限制并发、缓冲、目录扫描和带宽占用，优先音视频与输入。 | 执行大文件双向传输时，通过带负载的交互延迟与音频连续性指标。 | M3 |
| FS-07 | **文件授权边界。** 主机以登录用户权限及授权根目录处理任务。连接撤销时暂停或终止任务。 | 对不同系统的符号链接、重解析点、跨目录移动和 TOCTOU 场景验证实际文件句柄范围。 | M3 |

## 浏览器与自托管

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| WEB-01 | **浏览器控制电脑。** 自托管 HTTPS 页面按设备 ID 连接并完成端到端认证。提供音画、键鼠、缩放、多屏及会话结束。 | Chrome、Edge 形成完整桌面浏览器基线。Firefox、Safari 验证核心远控及能力降级。 | M4 |
| WEB-02 | **浏览器剪贴板和文件。** 支持相应权限时可选本机目录，读取用户授予的范围。其他浏览器提供选文件上传及显式下载。 | 拒绝目录或剪贴板授权后正常远控，操作提示可解释。 | M4 |
| WEB-03 | **内网部署。** 浏览器、主机和自托管服务可部署在同一隔离网络，通过可信 HTTPS 同源访问服务。 | 公网断开后，局域网域名、证书和静态资源仍有效。 | M4 |
| WEB-04 | **浏览器交互约束。** 处理播放手势、全屏、浏览器占用快捷键、焦点丢失和移动网络变化。 | 用户可发送常用组合键。在标签失焦或关闭时释放所有已按键位。 | M4 |
| OPS-01 | **可自托管的设备目录和信令。** 提供版本发布物、容器部署、TLS、备份恢复、健康检查、配额和最小配置示例。 | 用新部署从零注册主机并建立会话。停用一个部署不影响同网段原生 IP 直连。 | M4 / M7 |
| OPS-02 | **可自托管的 NAT 中继。** 按部署配置 STUN、TURN 和短时凭据。控制并发、速率与中继出站策略。 | 从仅允许受控出站的测试网络进入，验证直连失败后的 TURN 路径和过期凭据处理。 | M4 |
| OPS-03 | **安装、升级与回滚。** 各平台包以各自的签名流程发布。升级包含协议兼容、数据迁移和失败回滚。 | 支持矩阵上从前一版升级并保留本机身份、偏好和文件任务。 | M7 |
| OPS-04 | **故障与服务可观测性。** 服务记录连接率、失败类别、当前会话和中继资源；客户端提供本地诊断。 | 模拟服务重启、数据库恢复、证书变更和多设备并发。监控不依赖外部托管。 | M7 |

## 终端、Pi 与移动端

| 编号 | 功能与行为 | 验收 | 阶段 |
| --- | --- | --- | --- |
| CLI-01 | **独立终端主控。** 根据服务器和设备 ID 建立会话，默认只读并静音。密码使用无回显输入，显式申请键鼠。 | 独立构建、安装和启动。在无 Flutter GUI 的主控机器上完成连接及控屏。 | M5 |
| CLI-02 | **ANSI、Kitty、Sixel。** 按终端能力自动选择渲染器，支持手动指定和降级。ANSI 用色块表示像素，Kitty/Sixel 有条件输出图像。 | 覆盖代表性终端、tmux/SSH、窗口尺寸变化和协议不可用场景。 | M5 |
| CLI-03 | **局部缩放与平移。** 支持适配整屏、放大细节和移动视口。远端尺寸变化后更新坐标并限制视口边界。 | 将边缘和中心目标放大，点击命中点在放大前后一致。 | M5 |
| CLI-04 | **持续本地命令模式。** 进入命令模式先释放远端按键。切屏、缩放、画质、静音、统计、退出等由本地解释，显式恢复才转发按键。 | 远端模式下回车等按键传到远端；本地模式连续执行命令不会误操作被控端。 | M5 |
| CLI-05 | **Pi 扩展。** Pi 编程助手通过扩展组件展示会话状态和视口，由用户输入完成控制。连接和解码由独立 Rust 程序执行。 | Pi 持有终端渲染和键盘焦点，子进程退出能恢复 Pi 界面。扩展遵守同一身份认证和控制权限。 | M5 |
| CLI-06 | **远程 Shell。** 与终端观看和本地命令模式分开，需主机单独显式开启及授权。Unix PTY 或 Windows ConPTY 以被授权的普通用户运行。 | 只读/键鼠权限无法打开 Shell，撤销后终止 PTY 和关联任务，敏感内容不进入诊断。 | M5 |
| MOB-01 | **手机和平板主控。** iOS/iPadOS 和 Android 控制电脑，布局支持横竖屏、触控板、缩放和外接键盘。 | 与 Windows、macOS、Linux 目标机连接，切换触控和外接键鼠后坐标准确。 | M6 |
| MOB-02 | **移动网络和生命周期。** 主控与系统音频、屏幕锁定、后台切换配合。恢复前验证原会话授权，超时后要求重连。 | 在 Wi-Fi、移动网络切换和前后台过程中无卡死、粘键或未经授权自动恢复。 | M6 |

## 完成判定
